This app stores everything (events, reservations, requests, signs, lots) in your Supabase project, so it has nothing to run on until it’s connected. There is no offline mode.
  1. Run schema.sql in your Supabase project’s SQL editor.
  2. Add staff accounts under Authentication › Users › Add user.
  3. Paste your Project URL and anon public key into SUPABASE_URL and SUPABASE_ANON_KEY near the top of this file’s script, then reload.
